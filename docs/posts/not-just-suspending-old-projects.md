# Not just suspending old projects

The true end of the legacy projects (but not Sheer).<!-- more -->

For the past years, I was making command creations as an attempt to shift users away from Forge mods, however there are still some "ongoing" projects that I have lost, such as Bunny 350 Matrix Series 3 and Adventure. Today, I am announcing that these rest of the projects will no longer be available to be developed, and will become scraps that are exclusive to our followers.

<img src="/blogs/media/not-just-suspending-old-projects/b3adventure.png" alt="Image the lobby in Bunny 350 Adventure"></img>
## Why did Bunny 350 Adventure finally canned?
This is because CAD took my hobby business. Well that is way too serious. Actually, it's because of lacking of other ideas, beside trying to find an evil sheep, track down the pin while the universe wants the player to be blown off, and a small elytra track. It used to have fifty levels, but then dropped to exact twenty. I've used to have a huge ambition of having fifty, but then that's way too many.

The requirement was used to be an achievement when I reach 100 (real) subscribers on my YouTube channel (The keyword is real because I "experimented" with a website that allows sub-botting (the not-real subs), which is a violation of API use and pisses people off if you love making content and do this at the same time), and then because I feel like my laziness can't stop me from this project, I decided to add the slowest date of 2017, and then 2018, and the final change being November of 2019, these didn't happen, and so trying to reach such small number of subs as I left my YouTube channel.

<img src="/blogs/media/not-just-suspending-old-projects/bunny_350_matrix_series_3_unveiling.jpg" alt="Image of Bunny 350 Matrix Series 3 when it is going to be unveiled"></img>
## Next, why must Bunny 350 Matrix Series 3 be scrapped too?
This project is almost complete, heck, the wiki title still calls it **New Bunny 350 Matrix** before I scrap it! Except also because my lost interest in these command creations. Whatever, All I need is to make variables (to Minecrafters it's called **scoreboards**) for user-made matrix displays and bobs-an-uncle, except that I am no longer supposed to make it via command blocks, and instead via data packs. And because it's a world, not the add-on mod, it really makes me look like something else, so this project is also scrapped.

It was supposed to be released in the early 2019, which was supposed to surpass data packs, and I even have a huge ambition in releasing it for Bedrock Edition, except that I want it to be built after Java version but since that version was incomplete, it never happened. (and yea sometimes the stomachache curse hits me when trying to build this project lately)

## Was Sheer 2017 also scrapped?
For this, no, it was still running, except that since this is special, it does not run 24/7, and I intent it to run unscheduled. And because I did not classify it as legacy project as I like visiting it more often than other Minecraft projects, beside my survival world.

## Now how do I access these abandoned projects?
<s>Followers of Oitswilliam Pang can access early-access projects, and because of this, they can also access certain abandoned projects, these include the following scrapped projects and the main lobby for Bunny 350 Server.</s> For Christmas Adventure I would like to release it publicly. I was thinking of limiting access of most of these maps to my followers, but the decision was changed to make it available for everyone. For these maps, or worlds, users (whether followed or not) can head to my miscellaneous projects' abandoned projects folder, except for Sheer (2015) (which is placed in my Google Drive).

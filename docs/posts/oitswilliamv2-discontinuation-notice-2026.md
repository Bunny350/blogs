# Support for RepRapDiscount 12864, 24V passive PoE and Morefine M6 mount on OITSWILLIAMV2 will be removed on June 15

!!! note
    This announcement has also put in [GitHub](https://github.com/Bunny350/OITSWILLIAMV2/issues/4), where users can comment at anytime, although the content is slightly different.
    
Hi everyone, this is a public service announcement regarding these deprecated mods and parts for OITSWILLIAMV2. <!-- more --> As we drive for the future experience, but these mods can't help, they will be removed when the commit on June 15 pushed. But users can still access these removed mods by surfing the history. 

- The following mods compatible prior will be removed:
    - Display configuration file made for RepRapDiscount 12864
        - On the official repo, models of it was not updated for V2.4.
    - 24V passive Power over Ethernet configuration file
        - The use of it is dull, ever since the mobility mod mostly scrapped.
    - Morefine M6 mount
        - Assembly manual has been released before removal.
        - Despite its let users run Windows, it still didn't reach the goal, where it's still far. And Microsoft is being rude and constrained such computer's performance, and that put the goal way further away.
- This change only affects new users, if you still want to surf these mods after removal, you can visit this link https://github.com/Bunny350/OITSWILLIAMV2/tree/ac962b0f14a127731bdb723d3908649bfd60b812 with the commit hash starting at ac962b0.
- Display configuration file made for BigTreeTech Mini 12864 will stay unaffected.

Thank you for understanding. If you have any other questions, you can contact me, via email, social platforms or chat groups with [links available here](https://www.oitswilliam.com/support) .
